# cw-font-pack-sc: the faces it bundles

Every face here is a Noto face from https://github.com/google/fonts at a pinned commit (Noto Color Emoji from the
googlefonts/noto-emoji v2.051 tag, unmodified), by the Noto Project Authors, subset by cw-render's `build-fonts.py`.
Each is under the SIL Open Font License 1.1, whose full text ships beside it in `fonts/` (`NOTO*-OFL.txt`). Each
file's name table still carries its copyright and licence.
